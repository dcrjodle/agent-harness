# Git
- Branch per task: `feat/<slug>` | `fix/<slug>` | `chore/<slug>`.
- Conventional commits: `type: summary` (feat, fix, chore, refactor, docs, test).
- Never commit: `.env`, `MACHINE.md`, secrets, build output.
- PR via `gh pr create --fill`; link the issue.
- Never force-push. Never push to main.
